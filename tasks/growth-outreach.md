# Growth & Outreach Strategy: ScholarPoster

## Core Goal
Organically increase the number of active users (researchers/academics) and GitHub stars by making the tool indispensable and highly discoverable.

## 1. Meta Promotion (ScholarPoster for ScholarPoster)
- [ ] **Optional Signature:** Implement an opt-in "Posted via [ScholarPoster](https://github.com/dsifry/mastodon)" footer for cross-posts.
- [ ] **Tutorial Threads:** Use the tool to post a thread about a research paper, ending with a "How I posted this" post linking to the repo.
- [ ] **Automated "Growth" Posts:** Periodically post a summary of "Total Cross-Posts Managed" to showcase project activity.

## 2. Community Engagement (Sci-Sky & Academic Mastodon)
- [ ] **Instance Outreach:** Contact admins of `fediscience.org`, `mstdn.science`, and `ecoevo.social` to list the tool in their resources.
- [ ] **Bluesky Starter Packs:** Get ScholarPoster added to "Science" and "Academic" starter packs.
- [ ] **Professional LinkedIn Angle:** Position the tool as a way to maintain a professional LinkedIn presence with zero extra effort.

## 3. GitHub Optimization (The "Star" Magnet)
- [ ] **Visual README:** Add a GIF or high-quality screenshot of the CLI in action.
- [ ] **Badges:** Add badges for CI status, 100% code coverage, and Python version support.
- [ ] **Governance Docs:** Create `CONTRIBUTING.md` and `ROADMAP.md` to show project maturity.
- [ ] **GitHub Topics:** Exhaustively tag the repo: `mastodon`, `bluesky`, `cross-posting`, `academic-tools`, `python`, `activitypub`, `at-protocol`.

## 4. Solving Academic FOMO
- [ ] **Positioning:** Frame ScholarPoster as a "Research Impact Multiplier."
- [ ] **Impact Showcase:** Create `docs/SUCCESS_STORIES.md` showing how a single post gained 5x visibility via cross-posting.

## 5. Workflow Integration
- [ ] **ORCID/Zotero Integration:** Explore ways to trigger cross-posts when a user adds a new publication to their ORCID or Zotero.
- [ ] **BibTeX to Post:** Implement a feature to convert a BibTeX entry into a formatted cross-post.
